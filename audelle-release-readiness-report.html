What changed

Export

Valid multi-track ZIPs

The central-directory local-header offset moved from byte 38 to the ZIP-specified byte 42. The archive remains STORE-only, so already-compressed best-audio bytes are not degraded or pointlessly recompressed.

Audio quality

Original bytes, accurate formats

yt-dlp metadata now identifies the selected best-audio format. WebM/Opus, M4A, OGG, and MP3 are labeled correctly; no transcoding is introduced.

Security

Bounded stream lifetime

The four-slot audio concurrency limit now remains held through transfer completion or disconnect. Resolved URLs must be HTTPS Google Video media hosts; redirects are disabled.

Playback UX

One visual control language

Transport controls are an accessible named group and reuse Audelle’s pill controls, ember focus treatment, restrained glow, icon micro-motion, and reduced-motion path.

Catalog correctness

Provider failures degrade safely

Unknown years cannot satisfy an explicit range, malformed view strings do not crash parsing, and transient album-year failures are not permanently negative-cached.

Test discipline

Stable merge gate

Four third-party tests are marked live and skipped by default. The live year-filter smoke test must return at least one track instead of passing vacuously.

Delivery

Immutable homelab preview

A pinned multi-stage image, restricted Kubernetes workload, probes, resources, deny-by-default policies, Argo CD ownership, encrypted tunnel credential, and dedicated home-node connector are deployed.

Streaming

Fast best-audio proxy

Deno supports current yt-dlp player challenges. Only safe media headers are preserved, and an open-ended upstream range avoids Google’s full-object throttle while returning identical original bytes.

Open findings

Medium

Public audio proxy is not playlist-bound

Any syntactically valid YouTube ID can use /api/audio/{video_id}. The stateless design has no capability proving Audelle generated that ID. Before public release, add shared edge rate/cost limits; decide separately whether signed, expiring download capabilities are worth the state/API complexity.

Medium

Body limit trusts Content-Length

The application’s 64 KiB request guard does not independently bound chunked bodies. Enforce the real receive limit at ingress and preferably at ASGI receive-stream level.

Medium

Cloudflare rate-limit write is not authorized

The configured Cloudflare credential can read rulesets but returned authentication error 10000 when adding the audio rule. Application concurrency is bounded at four, but the planned shared edge limit still needs a token with Rulesets write permission.

Acceptance

Audible playback in a human browser

Headless Playwright proves IFrame readiness and enabled controls but YouTube does not enter its audible playing state in the headless runtime. A short human preview check should confirm play/pause and seek before merging to main.

Low

Test-client deprecation

The deterministic suite emits a Starlette warning that its httpx-backed TestClient path is deprecated in favor of httpx2. Schedule the compatible test-client migration before it turns into a forced dependency upgrade.

Game plan to main and production

Human preview acceptance

Open audelle-preview.astatide.com in a normal browser and confirm audible play/pause, seek, one full track transition, mobile layout, and reduced-motion behavior. The automated generation, controls, ZIP, and media checks are already green.

Close edge abuse control

Grant a narrowly scoped Cloudflare Rulesets write credential and add the reviewed host/path rate limit for /api/audio/*. Keep the application four-stream semaphore and ingress body limit as defense in depth.

Merge Audelle

Review the release branch and HTML report, require the current GitHub Actions run, then merge the application PR to main. Record the final source SHA and published image digest.

Promote immutable production

Create a production overlay from the proven preview manifest, pin the main-branch image digest, preserve the homelab node selector and dedicated tunnel pattern, and use a production hostname without exposing a NodePort or home address.

Operations and rollback

Add application-level dashboards and alert delivery, document the prior digest, and rehearse an Argo CD rollback. The service is stateless, so recovery centers on image, GitOps, encrypted configuration, and DNS/tunnel versions.
